# Conversion matrix

Generated by `./build.sh conformance`. Every operation of the app is run on a real generated file and judged by an independent reader, never by the code that wrote the result.
A conversion that only renamed or copied a file fails the generic checks (the real format is sniffed from the bytes, the result must decode, differ from the input and keep its content).
